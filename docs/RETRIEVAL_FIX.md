# 中文单词漏检修复（2026-09-24）

R04 的问题是“根据资料，这个物体走了多少米？”，资料给出每秒2米、持续3分钟。旧检索仅命中“物体”一个中文片段，因阈值至少两个命中而过滤掉，导致模型没有看到数据。

本次保留原有多片段匹配、英文技术词、标题及上下文预算，补充 Intl.Segmenter 中文完整词匹配：当只有一个中文片段命中时，要求问题和正文确实共享一个有意义的完整词。过滤“资料、内容、要求、系统”等泛词，避免将一般说明误当依据。并未取消所有匹配阈值，也没有把全部资料强行送给模型。

验证：新增单词召回、泛词、偶然字串重叠、无关正文和预算用例；原30题仍为25/25有依据题预期来源进入前5、5/5无依据题空检索。类型、lint、领域、服务端流式检查与构建通过。

真实服务复跑新增8题，8次完成、8道核心预期符合；R04引用原文并计算360米。R06检索到“没有考试安排”的片段，仍明确无法提供确切考题。结果见 evaluation/reliability-retrieval-fix.json；修复前7/8及失败原始记录保留在 reliability-live.json。不能将同一开发集复测当作独立准确率评估。

局限：仍为词法检索，不保证同义改写或复杂跨段推理均能召回；补充解释没有自动事实核查。真人试用、真机软键盘及独立教材盲测仍待外部验收。
