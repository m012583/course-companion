# 新版真实试用任务与记录

状态：待真实参与者执行。以下是试用工具，不是已经完成的用户研究。

## 环境

在第二台电脑按 README 从完整源码安装；手机使用经单独配置并验证的测试环境。不要将仅供本机使用的服务直接暴露公网。参与者建议 3–5 名大学生，不收集姓名、账号密钥或真实敏感教材；用匿名编号 P01–P05 和自编资料。

## 不提供现场步骤提示的任务

1. 找到示例课，并从教材读到第二段。
2. 将一段内容保存成笔记，关闭页面后找回。
3. 体验示例题，核对后完成一道练习。
4. 找到答错的知识点和教材依据。
5. 将错题安排进复习，再从计划打开对应练习。
6. 返回教材，确认阅读位置保留。
7. 删除一份自己创建的内容，再从回收站恢复。
