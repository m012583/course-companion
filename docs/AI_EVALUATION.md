# DeepSeek 真实 AI 评测记录

2026-09-23，以本机 /api/chat 调用 DeepSeek deepseek-flash，使用既有自编 20 个资料片段及 30 道题。未修改用户课程资料。原始回答与逐题复核见 evaluation/ai-live-deepseek.json。

## 结果

- 真实请求 30/30 完成；另有 1 次预检调用，不计入题集。
- 25 道有依据题的核心答案符合预期，预期来源均被引用。但 Q07、Q08、Q25 存在条件或措辞不严谨，不能计为全答案无误。
- 5 道无依据或越界题均说明没有原文依据；没有编造押题答案、私人号码或服务密钥。模型仍可补充标注的通用知识，这不是完全拒答。
- Q26、Q27 出现“无对应原文”占位文字：模型在说明中提到来源编号，后处理替换了未知编号。没有生成真实引用，但展示需改进。
- Q26、Q29 的通用知识扩展未独立核验，不据此宣称事实正确。
- 单题耗时中位数 3.754 秒，P95（最近秩法）12.425 秒，最大 21.140 秒；30 次请求累计 161.449 秒。包含本地处理、检索、网络与生成，不是纯模型推理延迟。
- 未采集 token 用量与账单，因此不报告费用。

## 具体改进点

1. Q07：贝叶斯公式多个假设的求和分母，除互斥外还需要假设穷尽样本空间。
2. Q08、Q25：独立是方差可加的充分条件，不是必要条件；两变量不相关且方差存在时也可相加。
3. 无依据回答不应输出来源编号示例，避免占位文字干扰。
4. 后续增加针对充分/必要条件、资料内指令注入、多轮追问的独立测试；不能只用同一开发集反复优化后声称泛化性能。

## 配置错误保护

三个 AI 接口增加密钥格式校验：含中文、内部空白或控制字符时，在请求服务前返回明确提示，且不回显密钥。测试命令为 node tools/test-ai-config.mjs，测试仅使用假密钥，不调用外部服务。

## 适用范围

本次由 Codex 助手对回答和资料逐条复核，不是独立人工盲评或真实用户试用。自编小型题集不能代表真实教材表现，也不能得出通用准确率。已有检索报告和早期未配置服务的失败记录保留作为历史，不应混淆。
