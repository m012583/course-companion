# 课伴研学增强版 0.3 更新与验收

日期：2026-10-08。以用户提供的“课伴研学增强版 0.2”源码为基线，保留教材校准、课程导览、两题自测、流式问答及原有视觉风格，新增功能融入现有页面。未覆盖现用旧项目或原增强版目录。

## 本次改动

| 入口 | 新行为 | 边界 |
| --- | --- | --- |
| 教材与自测 → 题库与错题 | 手工建立选择题、判断题；从既有自测导入草稿；确认后练习；题目编辑、查找、软删除与恢复 | 首批不含主观题自动评分；AI 自测的解析仍需人工核对 |
| 练习结果 | 保留每次作答时的题目版本、选择与标准答案；记录错因、再次练习、预览后加入复习 | 改题不覆盖历史；统计仅代表实际做过的题目 |
| 近期练习反馈 | 按知识点汇总作答、错误、尚待巩固的题目；可点击查看错题 | 不推断整门课程掌握度，不采用尚无长期数据支持的记忆算法 |
| 笔记草稿 | 关闭编辑窗后继续保留；刷新恢复；纳入完整备份；新建另一篇时先处理已有草稿；丢弃需二次点击 | 浏览器副本与服务端版本不一致时不强行覆盖服务端草稿 |
| 设置与备份 → 本机恢复点 | 修改前每隔至少 30 分钟留档，最近 20 份；恢复前另外保留最近 10 份；预览后恢复 | 恢复点与当前数据在同一电脑，不能替代下载的完整迁移包；迁移包不包含整个恢复点历史 |
| 资料 → 识别扫描文字 | 本机中英文 OCR，支持 PDF/PNG/JPEG/WebP，进度与停止；原附件不变 | PDF 每次最多前 20 页；不保证复杂公式、低清照片识别质量；停止会保留原提取结果 |
| 资料 → 校正提取文字 | 分段核对并手动修改用于检索的正文，保留页码 | 不更改原 PDF；旧讲解与历史引用需复核 |
| 原文引用 | 新引用带片段与资料版本；突出显示历史引文，显示其所在段落；教材变化、删除或来源缺失有提示 | PDF 原文件沿用页码跳转，尚不提供 PDF 画布上精确字框高亮 |
| 教材校准 | 人工确认具体原文对应关系，教材文字变化后提示重新核对 | 人工确认是对应关系，不是自动事实认证 |
| 启动器 | 检测依赖锁文件变化，更新时重新安装锁定依赖，准备本地 OCR 资源 | 首次安装/更新需要网络和 Node.js；没有改为免安装 EXE |

## 数据与兼容性

- 增强版 0.2 的 `course-kb-bundle` 第 2 版迁移包继续支持；题库与作答保存在课程的 `studyLab.practice`，原 `studyLab.checks` 不改写。
- 作答中的题目和来源是独立历史副本；导入时会一并重映射其中的附件编号。
- 增加可选 `noteDraft` 字段及独立 `workspace_snapshots` 表。旧工作区首次运行时按需创建恢复点表，不删除旧表。
- 工作区更新继续使用 revision 冲突保护。快照与替换在数据库事务内完成；写入失败一并回滚。
- 原始文件仍被工作区或恢复点引用时，永久删除接口会拒绝删除。
- “课伴知识库”旧分支的其他完整备份格式不假称兼容；如格式不是增强版第 2 版迁移包，界面明确拒绝，不能通过手改版本号导入。
- 回退时重新使用原增强版目录及其原数据。先另存 0.3 的完整迁移包，不建议将含新题库的备份导入旧程序再导出，以免丢失新字段。

## 验收证据

新增自动测试覆盖历史作答不被改题影响、判断题校验、附件重映射、SQLite 事务回滚、冲突拒绝、快照保留上限、草稿备份与引用变更检测。执行结果记录在 `evaluation/update-verification.json`。

- `evaluation/ui-update.json`：无头 Edge 的建题、作答、复习、重复练习、删除恢复及 1440/768/390 像素布局检查。
- `evaluation/protection-ui.json`：真实浏览器草稿刷新、完整备份、本机 OCR、人工校正、恢复点导出与附件保护。
- `evaluation/migration-update.json`：全新本地工作区，真实 D1/R2 附件字节校验、编号重映射、损坏备份与版本冲突。
- `evaluation/expanded-retrieval.json`：三门自编短讲义 40 道固定问题。36 道有依据问题的首条命中，旧版 32、新版 33；前三条均命中 35；4 道无依据问题均返回空。该集合不是独立盲测，不衡量模型答案准确率或学习效果。原 6 题回归及原始真实 AI 对照记录继续保留。

本次没有运行付费 AI 评测，没有第二台实体电脑、真实手机软键盘或真实用户试用结论。

## 依赖审计尚未完成修复

本次 npm 官方审计返回 29 项：3 critical、15 high、7 moderate、4 low，包含开发工具与间接依赖。明细和建议版本保存在 `evaluation/dependency-audit.json`。这不是 29 个均能通过本软件界面直接利用的漏洞，也不表示它们已被排除。

兼容修复预检遇到 `react-server-dom-webpack` / `vinext` 依赖解析冲突；部分自动建议涉及大幅降级，未使用 `--force` 或忽略 peer 依赖。当前保留已验证依赖，默认仅本机监听。公开部署前需单独解决依赖兼容与安全复测；本次不声称安全审计通过。

## 运行和回退

1. 双击更新目录 `start.cmd`，等待启动器显示本机地址。
2. 原增强版有个人数据时，先在原版导出含附件迁移包，在更新版“设置与备份”选择、预览并确认恢复。
3. 初次验证建议使用原创示例课：两题自测 → 导入题库草稿 → 核对并确认 → 作答 → 错因 → 复习。
4. 需要回退时关闭更新版启动窗口，打开原增强版目录的 `start.cmd`。原版源码与数据保留。

软件源码包不包含 `.env.local`、个人数据、测试工作区或演示视频。首次安装会准备 OCR 资源。
