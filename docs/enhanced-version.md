# 研学增强版：改动与验收记录

日期：2026-10-03。此版本位于原项目的 `work/competition-v2`，原版源码和原有数据独立保留。ZIP 提供干净的软件源码，个人数据通过网页里的含附件迁移包传递。

## 五项改动

| 方向     | 当前实现                                                                 | 使用边界                                                    |
| -------- | ------------------------------------------------------------------------ | ----------------------------------------------------------- |
| 教材校准 | 选择教材、编辑识别目录、知识点覆盖检查、缺失目录补充、章节生成引用原文   | 规则和检索辅助核对；不自动判定教材与讲解的所有语义矛盾      |
| 检索验证 | BM25 排序、有限词表、可选 AI 查询改写，免费回归与真实回答对照            | 没有 embedding 或向量数据库；词表覆盖范围有限               |
| 学习反馈 | 两题诊断、错题知识点、教材解释、复习任务预览、确认保存                   | 控制流程，不宣称已实现自主 Agent 或 MCP；两题不能评估整门课 |
| 阅读等待 | 真实 SSE 流式回答、停止、过程状态、部分回答保留，章节来源与独立提问      | 取消不能撤销已经计费的生成；页面视觉验收待用户手动确认      |
| 稳定迁移 | 独立端口与数据、同目录重复启动复用、无密钥示例、附件备份和恢复、冲突保护 | 首次需 Node.js 与联网安装；不是完全离线桌面程序             |

## 演示路线（约三分钟）

首页 → 示例线性代数 → 教材与自测 → 查看一个原文片段 → 两题自测 → 故意错一道 → 查看解析 → 预览复习安排 → 确认保存 → 打开复习计划。然后回到课程导览，点知识点提问查看独立对话与流式输出。最后展示设置中的含附件备份恢复。

示例讲义为原创短文，已经标明它不是学校教材。没有密钥时仍可完成校准、自测和计划保存的主流程；真实 AI 问答需要自己的服务配置。

## 检索、回答和引用评估

数据：原创线性代数讲义的六个小节。六题公开回归包含明确标注的词表问法；另外四题固定标准答案比较旧词项检索与“BM25 + 可选 AI 查询改写”。两边使用同一已配置模型、同样的答案提示，问答不保存到用户工作区。

2026-10-03 的真实请求使用 `deepseek-flash`。四题结果：两边首条命中均为 3/4，相关小节召回均为 4/4，引用编号有效且引用标准小节均为 4/4。Codex 逐条对照金标准及实际引文，八份答案的核心结论与引用均符合；这不是外部专家或用户的人工盲审。

六题免费回归两边均为 6/6。因此目前**没有测出准确率提升**。不能把小样本满分写成通用 RAG 效果或学习效果证明；需要补充真实教材、更长文档、近似干扰段落和独立标注的问题，再评估收益。不要为了让新版分数更好而事后更改这组金标准。

原始回答、所检索片段、所引片段、预置标准答案和自动指标保存在 `evaluation/live-comparison.json`；本地检索结果保存在 `evaluation/retrieval-comparison.json`。免费界面不会自动重复 API 评估。按 README 命令可显式重跑，结果会因模型更新和随机性变化。

## 运行验收

- 64 项自动测试覆盖原有功能和新增检索、自测、流式解析、取消上游请求、损坏备份拒绝、恢复失败回滚、附件编号重映射等路径。
- TypeScript 检查、所改文件的 lint 和生产构建通过；构建用于验证可打包，不代表已部署公网。
- 在无 `node_modules`、无密钥、无旧数据的解压目录由启动器完成 `npm ci` 和首次启动；同目录重复启动可识别已有服务。
- 干净目录迁移检查已通过，记录在 `evaluation/migration-check.json`：真实本地存储、原始附件字节校验、诊断答案及计划关联、错误备份不覆盖、版本冲突拒绝。
- 原版清单的 128 个文件逐个进行 SHA-256 对照，全部保持一致；测试期间主增强版工作区维持第 18 版，测试没有写入它。
- 干净目录测试发生在同一台 Windows 电脑，不能代替第二台实体电脑或 macOS/Linux 的验收。
- localhost 浏览器自动验收受到本任务安全策略拒绝；未改用其他浏览器绕过。用户需要手动确认首页、教材页、窄屏布局和完整交互显示。
- 首次安装的 npm 审计报告提示现有依赖中有 5 个中等级、2 个高等级问题；进一步拉取审计明细遇到证书/连接错误，尚未完成归因。本次没有盲目升级依赖或声称安全审计通过，版本仍按本地使用交付。

## 沿用与成本

继续复用已有课程导览、Markdown / KaTeX、原文阅读器、图谱、回收站、复习计划、D1/R2 本地存储及已记录的开源参考。新增代码没有增加 npm 依赖。开发目录复用原项目安装的依赖；干净压缩包不含该目录，接收者按锁文件独立安装。

仅打开图谱、教材校准、示例自测或备份不会请求 AI。AI 改写默认关闭；显式开启才额外请求，最多三条短改写。未将任何密钥写入源码、网页备份或分享 ZIP。
