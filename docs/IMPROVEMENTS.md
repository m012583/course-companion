# 2026 年 9 月软件改进验收

本轮完成数据恢复、学习流程和工程检查改进。真实模型现已完成自编 30 题评测，见 [评测记录](AI_EVALUATION.md)；真实用户试用仍未完成。

## 已交付功能

| 功能 | 入口与行为 |
| --- | --- |
| 完整备份 | 设置与备份 → 下载完整备份，包含工作区、回收站及全部引用附件，使用版本号和 SHA-256 校验 |
| 恢复预览 | 选择完整备份，显示课程、笔记、任务、附件和回收站数量；明确确认后替换工作区 |
| 恢复保护 | 新附件使用新 ID；D1 事务中保存旧状态快照并检查 revision；旧原文件不覆盖 |
| 恢复历史 | 设置中查看恢复前快照，下载后按同一流程恢复 |
| 回收站 | 课程和笔记删除后可恢复；课程包含笔记、对话、任务；恢复笔记前须有所属课程 |
| 阅读衔接 | 资料页分段阅读自动记住位置，首页继续阅读；支持选文提问及带来源保存笔记 |
| 复习记录 | 没答对、吃力、答对三档自评；保存回答与时间，笔记内展示最近 10 条，完整历史随备份保存 |
| 笔记关联 | 按共同标签和同一章节推荐候选，用户确认才建立关系；图谱支持标签筛选 |
| 模型配置 | 支持输入服务实际模型 ID；留空使用服务端 OPENAI_MODEL |
| 工程质量 | 抽出工作区类型、校验、备份、回收站和阅读组件；修复全项目 19 项历史 lint 错误 |

课程删除按钮仍位于左侧。章节、资料列表项、任务和对话的删除沿用原有确认流程；只有课程与笔记进入回收站。

## 已执行验证

- 类型检查、全项目 lint、领域测试、生产构建通过。构建仍提示个别客户端包超过 500 kB；尚未进行首屏性能基准测试。
- 原增删改查浏览器回归全部通过，使用内存接口。
- 独立 3012 端口真实 D1/R2：附件字节校验、损坏备份拒绝且旧数据不变、旧 revision 冲突、新文件标识、恢复前快照再次恢复、原文件保留和同源拒绝分支通过。
- 重启本地服务后，工作区、revision 和引用附件字节保持一致。
- 新增功能在真实存储上的 13 项浏览器检查通过，包括导入预览、恢复、阅读位置、笔记摘录、复习历史、回收站、左侧删除按钮、窄屏及外部写入冲突。
- 自编 30 题：20 道单一依据、5 道跨片段、5 道无依据或越界题。25 道有依据题的预期来源全部进入前 5 个结果；无依据题空检索从 2/5 改善至 5/5。这是小型开发回归集，不是独立盲测，也不是模型准确率。
- 历史首次真实评测因未配置服务返回 503；之后已完成真实 30 题，见 AI_EVALUATION.md。2026-09-24 新增 8 题回归及限制见 RELIABILITY_IMPROVEMENTS.md。

机器可读结果见 evaluation/retrieval-baseline.json、evaluation/retrieval-report.json。存储和浏览器运行日志、截图位于本机忽略的 test-results 目录。

## 边界与后续验收

1. 备份文件最大 150 MiB、单附件最大 20 MiB、引用附件总量最大 100 MiB、工作区正文限制 8,000,000 个 JavaScript 字符。上限附近的内存与耗时尚未压测。
2. 旧版裸 JSON 仅为本机文字副本，不包含附件，不能作为新版完整备份导入。
3. 永久删除回收站条目不自动清除恢复快照或物理附件；物理删除接口返回 409，防止破坏引用。暂未实现无引用文件的安全清理。
4. R2 与 D1 不是同一个事务。附件先暂存，D1 再原子切换；提交响应不确定时保留文件，避免已提交状态丢失附件。未模拟断电、磁盘损坏或数据库不可用等全部故障。
5. 真实模型回答、引用语义与时延已有本次开发集记录；费用与真实用户完成率仍待实测。执行方式见 TESTING.md 与 USER_TRIAL.md。
6. 仍是单用户本地应用，没有公网多租户权限或多设备同步。
