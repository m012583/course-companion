# 日常使用体验改进（2026-09-23）

## 已实施

- 笔记草稿在当前浏览器自动暂存，按草稿独立保留所属课程；关闭时选择继续编辑、保留草稿或放弃。刷新后可从右下角恢复。暂存失败会提示，不建议清理浏览器数据；草稿尚未保存为笔记前不包含在完整备份中。
- 保存状态区分本机服务保存和浏览器暂存，显示最近成功保存时间。设置的数据管理页显示最近下载完整备份的时间，不再暗示已备份到云端。
- 删除课程和笔记后可以撤销，侧栏提供独立回收站入口；课程内删除按钮继续位于左侧。撤销课程删除会恢复关联笔记、对话和任务。
- AI 问答支持逐步显示、等待秒数、停止生成及失败重试。部分回答标为未完成，失败保留输入问题；停止请求不能保证服务商不计费。
- 设置分为个人偏好、AI 服务、数据管理。支持 DeepSeek 及其他兼容服务，密钥输入隐藏，服务端保存，连接测试使用简短请求。首次保存覆盖本机服务的环境变量配置，不改写 .env.local；更换服务地址需重新输入密钥。配置接口限本机地址并拒绝跨站写入，仍不是公网多用户权限系统。
- Ctrl+K 或侧栏搜索课程、笔记、资料正文、任务和对话；结果显示所属课程和摘要，点击定位内容。最多展示 80 项，暂不包含未解析扫描件、回收站或草稿。
- 保存笔记时可取消加入复习，评分前显示具体日期，本轮可撤销上一次评分（刷新不保留撤销状态）。
- 资料页“并排记笔记”支持边读边写，选文笔记保留引用；窄屏自动上下排列。引用弹窗突出原文片段，手机端以底部面板显示；PDF 可打开对应页，不提供扫描图片精确坐标高亮。
- 手机首页压缩欢迎与复习区域，长课程名限制两行，卡片底部操作对齐；删除按钮保留左侧并降低视觉突出程度。

## 验证

- npm run typecheck、npm run lint、npm run test:domain、npm run build。
- npm run test:ai-config：三种 AI 接口在请求前拒绝无效密钥，不回显密钥。
- npm run test:comfort:server：流式 UTF-8 分片、引用清理、异常断流、取消信号、跨内容搜索；设置 COURSE_KB_VERIFY_BACKUP 可额外校验指定本机备份，文件不上传。
- npm run test:comfort：独立浏览器与内存 API 验证草稿刷新、关闭选择、取消复习、搜索定位、并排笔记、评分撤销、删除撤销、生成停止、重试、设置与窄屏。
- 原增删改查浏览器回归及独立 D1/R2 备份恢复回归。
- 真实服务配置另在隔离数据库验证：仅用假密钥，不调用外部模型；读取接口和完整备份不含密钥，跨来源写入被拒绝，更换地址不能复用旧密钥。

浏览器脚本需要 PLAYWRIGHT_MODULE 指向 playwright-core，并设置 COURSE_KB_TEST_URL。真实存储脚本沿用 TESTING.md 的隔离环境要求，禁止对日常工作区运行写入测试。

实际停止并重启隔离服务后，已核对工作区 revision 与正文、附件 SHA-256 和服务端 AI 配置保持一致。

本机真实 DeepSeek 流式冒烟验证返回 HTTP 200，收到 34 个事件并正常完成，回答含 1 处资料引用。运行器仅支持 manual/follow 重定向，现统一使用 manual 并拒绝非成功响应，避免跨地址转发密钥。
