# 课知屿 0.5.1：产品更名

日期：2026-10-21。原名称：课伴 · 研学增强版。新名称：**课知屿**；完整名称：**课知屿——AI 课程学习与知识管理平台**。

## 更新范围

- 浏览器标题、侧边栏品牌、首页提示与 AI 助手称呼统一使用新名称。
- 默认空间名称、原创示例工作区、导出正文备份和含附件迁移包使用新名称。
- npm 包名改为 `kezhiyu`，启动提示、README 和后续源码 ZIP 的名称同步更新。
- 历史技术 PDF、截图、旧版本更新说明及已有 Git 提交作为历史资料保留原名。

## 已有工作区与备份

只迁移旧版内置的默认空间名称；用户自定义空间名称及课程、笔记、附件、复习安排与草稿保留。读取已有工作区时显示新名称，下一次正常保存或导出迁移包时写入更新后的设置。旧迁移包导入时进行相同处理，不改写输入备份文件。

浏览器缓存键、`course-kb-bundle` 第 2 版备份格式、本地数据库和文件存储标识、环境变量名及实例识别协议继续兼容旧版。打开另一窗口不额外写入一次工作区，避免无编辑行为造成版本冲突。

本机项目目录已统一为桌面 `课知屿`，推荐启动入口为 `启动课知屿.cmd`，原 `start.cmd` 继续兼容。GitHub 仓库统一为 `m012583/kezhiyu`。Git 历史以新增提交记录此次更名，不改写原有提交、作者或日期。
