# 0.5：查找、复习与核对体验

本次从 0.4.0 的真实提交 `79a76e0` 继续开发，保留旧 Git 历史。升级前已保存完整 Git bundle、源码和含附件学习备份。

## 使用变化

| 位置 | 新行为 |
| --- | --- |
| 首页 | 合并重复的继续学习入口，按最近阅读或对话显示主要行动；统一资料计数，文本示例也计入 |
| 教材阅读 | 可直接展开问答；每门课在本浏览器记住分栏状态；手机压缩标题和管理入口，提供专注阅读 |
| Ctrl+K | 按课程和类型查课程、笔记、教材段落、练习与历史回答；教材定位可刷新，回答定位到具体消息 |
| 设置与备份 | 配置服务、模型、密钥和图片能力；加密保存后可主动测试连接；不在学习备份中保存密钥 |
| 今日复习队列 | 汇总到期及逾期笔记和计划任务，合并同题的到期任务；按 10/20/30/60/90 分钟预算显示，可暂缓到明天并取消暂缓 |
| 复习间隔 | 笔记与新生成的题目复习采用 1/3/7/14/30 天的连续答对规则，答错重置为明天；既有计划日期不被批量改写 |
| 复述练习 | 先闭卷复述，保存回答和原文快照，再自行核对或请 AI 提示已覆盖、遗漏与可能错误；可填写自己的判断与修正 |
| 引用核对 | 保存支持、部分支持、引用不符的人工意见，保留原文和相关内容快照及修正建议 |
| 笔记编辑 | 编辑前保存版本；编辑时预览正文；比较历史与当前内容，确认后恢复，恢复前内容也会留档 |

## AI 配置与边界

通过 `npm run start:local` 启动后，在“设置与备份 → 连接 AI”输入服务地址、实际模型 ID 和自己的密钥。“测试已保存的连接”只发送一句连接问候，不发送课程内容，但是真实服务会产生一次少量调用。

界面配置存于独立的 `local_ai_config` 表，AES-GCM 加密；启动器在被忽略的 `.env.local` 中生成 `COURSE_KB_AI_SECRET`。配置修改只接受本机地址和同源请求。此设计用于单人本机应用，不代替公网认证或多用户隔离。能够同时读取本机数据库和环境文件的人仍可能解密配置。

界面配置优先于环境文件；清除界面配置后恢复使用原环境配置。换电脑迁移学习备份后，需要重新配置 AI；不要公开 `.env.local` 或 `.wrangler/`。加密密钥缺失或变化导致无法解密时，可重新保存 AI 配置。配置失败不会向学习数据写入凭据。

复述的 AI 核对仅校验输出结构和引用编号，不保证每条建议语义正确。用户自评和人工引用意见均不是自动准确率指标。本次未引入 FSRS、PDF 字形级批注或新的向量库。

## 数据兼容与限制

- 迁移包仍为 `course-kb-bundle` 第 2 版；新增字段均为可选，0.4 工作区可直接读取。
- 笔记 `versions` 最多保留最近 20 个编辑快照，不为每次按键创建版本。图谱、收藏及原来源信息随当前笔记保留，不随正文历史切换。
- 复述保存在 `studyLab.retellings`，每课程最多 200 次；未提交的复述在 `retellingDraft` 保存。达到上限时阻止新增，不自动删除旧作答。
- 人工引用意见在 `citationReviews` 保存；每课程最多 1000 条。正文总量仍受原工作区 8 MB 限制。
- `preferences.reviewMinutes/reviewSnoozes` 只影响今日队列，不删除旧计划或标记未来任务完成。完成题目或笔记回忆，仅完成该对象的当前到期任务。
- 规则间隔提供可解释的默认安排，不声称是个性化记忆模型或学习效果验证。
- 回退前导出新版含附件迁移包；恢复旧源码时配合升级前备份，不直接让旧版写入新版数据。

## 验证

领域与接口测试涵盖搜索隔离、命中上下文、笔记恢复、复习去重和延期、备份重映射、配置加密、跨站拒绝、连接测试、无密钥拦截和复述引用校验。

`COURSE_KB_TEST_URL=http://localhost:独立测试端口` 下运行 `node tools/verify-experience.mjs`。脚本核对实例身份，使用专用测试课程、本机模拟 AI 服务和假密钥，结束后清理测试数据及配置。只能在未配置真实 AI 的独立测试实例运行。旧流程回归使用 `tools/verify-learning-flow.mjs`。

结果见 `evaluation/experience-ui-v1.json` 和 `evaluation/verification-0.5.json`。浏览器视口检查不等于实体设备测试；模拟服务通过不等于真实模型质量通过。真实服务评测、同学试用和实体设备验证仍待完成。依赖版本未在此版升级，0.4 审计中的剩余事项也未因此解决。
