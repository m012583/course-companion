# 页面布局改进与验收

日期：2026-09-23。基于课程、资料、笔记、问答、复习和设置页面的桌面/移动端检查实施。

## 已实现

- 笔记默认显示正文；引用紧随正文，复习设置和关联建议折叠展示。关联建议的标题、原因和添加按钮分区对齐。
- 问答占用当前可见窗口高度，消息独立滚动，输入框和发送按钮留在窗口内。监听 visualViewport 变化，在短屏时压缩布局。
- 移动端历史对话默认收起，可展开选择或新建对话。
- 复习入口置于任务与规划之前；复习过程中隐藏任务和规划，可退出本轮。学习规划和 AI 建议改为折叠区域。
- 并排阅读时默认收起资料列表，提供“切换资料”；桌面支持拖动分隔线或方向键调整原文宽度（40%–70%，Home/End 跳到边界）。窄屏采用上下布局。
- 课程标题与操作区更紧凑，“删除课程”保留左侧，“课程笔记”位于右侧。首页课程卡片缩小空白。
- 设置底部改为次要“关闭”按钮，AI 设置保留明确的保存操作。

## 验证

- `npm run lint`、`npm run typecheck`、`npm run test:domain`、`npm run build`。
- `npm run test:layout`：1366×900、768×1024、390×844、320×568、844×390、390×450；检查输入/发送可见、无横向溢出、对话列表折叠、分栏拖动与键盘操作、左侧删除、正文默认、复习顺序和退出、设置关闭。
- 单独模拟 visualViewport 从 844 缩为 450、布局窗口仍为 844 的情况，验证发送按钮可见。
- `npm run test:comfort`、`npm run test:crud`：模拟数据的浏览器流程。
- `npm run test:improvements`：仅在隔离测试库验证真实存储、摘录、回收站、备份恢复和冲突，共 13 项。
- `npm run test:comfort:server`：流式协议及服务端相关回归。

浏览器脚本需设置 `PLAYWRIGHT_MODULE`（Playwright 安装目录）和 `COURSE_KB_TEST_URL`（隔离服务地址）；详细环境见 TESTING.md。布局脚本拦截 API，使用自编数据，不调用真实 AI，也不修改用户资料。

## 边界

自动化使用 Windows Edge。可见区域缩小属于模拟测试，不代表完成 iOS/Android 真机软键盘、屏幕阅读器或真实用户试用。构建仍有大于 500 kB 的资源包提示，本轮未作打包性能重构。技术文档原 V1.1 PDF 未重排，本说明作为补充材料。
