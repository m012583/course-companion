# 真实用户试用执行单

状态：待开展。以下是试用方案和空白记录要求，不是已发生的用户研究。

邀请 3 至 5 位实际有课程资料管理需求的同学，在独立测试空间使用自编资料。每人预留约 20 分钟；记录用户是否同意参与，不收集密码、私人联系方式或无关学习资料。

## 连续任务

1. 新建课程和章节，上传一份测试资料，搜索指定词并打开原文。
2. 阅读到第二段，回首页后继续阅读，再选择原文保存带来源的笔记。
3. 添加标签，找到另一条相关笔记并建立关联，在图谱里定位它。
4. 不看笔记先作答，再核对、自评，并查看复习历史。
5. 删除一条笔记，再从回收站恢复；检查原文引用和关联是否可用。
6. 下载完整备份，在另一个空测试目录导入；核对课程、笔记和附件。不要在真实知识库演练覆盖恢复。
7. 若已配置真实模型，提一个有依据问题及一个无依据问题，逐句核对引用。

## 本轮补充任务（待真实参与者执行）

- 编辑笔记后关闭并刷新，找到草稿继续编辑。
- 从全局搜索找到资料中的概念，并创建不加入复习的参考笔记。
- 停止一次 AI 回答，判断哪些内容尚未完成，再重试。
- 误删课程后撤销，并核对其笔记与任务。
- 进行一次复习，撤销评分并重新自评。
- 用手机宽度阅读原文与笔记，记录需要反复滚动的位置。

请记录完成/未完成、耗时、误操作和原话反馈，不使用自动化测试代填。
