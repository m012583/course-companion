# 提交操作

本地已建立 main 分支和真实导入提交。仓库创建及发布仍需要明确远程仓库地址。

在 GitHub/Gitee 创建空仓库后，在本目录执行（用实际地址替换占位内容）：

```sh
git remote add origin 实际仓库地址
git push -u origin main
```

如果已有 origin，先 `git remote -v` 核对，不要盲目覆盖。通过 Git 凭据管理器登录，不把令牌写进地址或配置文件。

比赛截图要求仓库公开或给评委访问权限。公开后以未登录浏览器检查 README、源码、提交记录是否可读；私有仓库需按主办方要求授予评委访问权限。

最终核对：团队信息、开发来源、运行说明、真实 Git 历史、环境模板、测试记录、演示视频。源码 ZIP 不包含 Git 历史，不能单独替代仓库链接；备份 `.bundle` 可保留本地历史。

视频要求以用户提供截图为依据：5—8 分钟、MP4、分辨率至少 1080p，含普通话项目介绍、功能演示、AI 技术亮点，可配字幕。未提供团队信息前，不能声称最终参赛材料已经齐全。
