# 课伴：便携版使用说明

这个压缩包可以放到任意普通文件夹运行。每台电脑的数据独立保存在自己的本地运行目录中，不包含打包者的笔记、上传资料或 API 密钥。

## Windows 一键启动

1. 安装 Node.js 22 或更高版本：https://nodejs.org/
2. 完整解压压缩包，不要直接在压缩软件中运行。
3. 双击 `start.cmd`。
4. 首次运行会执行 `npm ci` 安装锁定版本的依赖，需要联网并等待几分钟；随后浏览器会自动打开。
5. 启动窗口需要保持打开。关闭窗口或按 `Ctrl+C` 会停止本地网页。

以后再次启动仍双击 `start.cmd`。依赖已存在时不会重复安装。

## macOS / Linux

安装 Node.js 22 或更高版本，在解压后的目录运行：

```sh
chmod +x start.sh
./start.sh
```

## 数据与隐私

便携包不包含制作者电脑上的课程、笔记、对话、复习记录、API 密钥或上传文件。每位接收者首次启动后得到一个独立的新知识库。

网页内“设置与备份”可以下载完整 JSON 备份作为留档，但当前版本还没有图形化恢复入口。上传的原始 PDF、DOCX 等文件也需要单独保存。

## AI 功能

知识图谱、手动关联、笔记、复习和资料管理不需要 AI API。

若需要 AI 问答或自动生成篇内概念图，复制 `.env.example` 为 `.env.local`，填写兼容 OpenAI Chat Completions 的服务地址、模型和 API 密钥，然后重启。不要把填有密钥的 `.env.local` 发给别人。

## 常见问题

- 提示缺少 Node.js：安装 Node.js 22 或更高版本。
- 首次安装失败：检查网络，删除未完成的 `node_modules` 文件夹，再运行 `start.cmd`。
- 提示端口 3000 被占用：关闭另一个本地课伴窗口或占用 3000 端口的程序，再启动。
- 需要改端口：在 PowerShell 中运行 `$env:COURSE_KB_PORT=3010; .\start.cmd`。
- 浏览器没有自动打开：手动访问 http://localhost:3000/
- Windows 弹出防火墙提示：本程序只绑定 `127.0.0.1`，供本机浏览器访问，不需要开放公网访问。
