# 课伴 · 研学增强版 0.3

本次新增题库与错题、草稿恢复、本机恢复点、扫描件 OCR 和引用复核。完整改动、验证结果与依赖审计限制见 [0.3 更新说明](docs/UPDATE-0.3.md)。

这是独立增强版本。原版文件与数据继续保留，新版使用自己的本地数据库和浏览器缓存。压缩包内没有个人课程、上传附件、运行数据或 API 密钥。

## 启动

1. 安装 Node.js **22.13 或以上版本**：https://nodejs.org/ 。
2. 将 ZIP 完整解压到普通文件夹；不要直接在压缩软件内运行。
3. Windows 双击 `start.cmd`；macOS / Linux 在目录执行 `sh start.sh`。
4. 首次启动自动运行 `npm ci`，安装锁定版本的依赖，需要联网；随后打开浏览器。默认地址是 **http://localhost:3002/**，端口被占用时会尝试之后十个端口，以启动窗口显示的地址为准。
5. 保持启动窗口打开，关闭窗口或按 Ctrl+C 会停止服务。再次双击会优先复用同一目录已经运行的实例。

也可在目录执行 `npm run start:local`。数据在本目录 `.wrangler` 中；不要为了修复启动而删除它。默认仅监听本机，不提供公网账号系统。无需 Cloudflare 账号即可本地运行。

## 先体验一条完整流程

首次启动有一门原创线性代数示例课，包含三章讲解、六个知识点和两道自测题，均可直接浏览，不调用 AI。

1. 打开示例课程的 **教材与自测 → 教材校准**，查看知识点对应的原文。点击来源可以核对讲义片段。
2. 到 **两题自测**，载入示例题并作答。提交后查看答错的知识点、解析和原文。
3. 点击生成复习安排，预览任务后 **确认加入复习计划**。只有确认才会保存。
4. 在 **检索验证** 中输入自己的问法，对比原版检索和新版检索；运行六题免费检查，下载实际结果。
5. 打开课程导览阅读已有章节。针对某段内容点提问，问题进入独立学习对话，不写回章节正文。

误删示例课可以在回收站恢复；设置中的“添加示例课程”不会覆盖其他课程。删除最后一门课后，刷新也不会自动塞回示例。

## 用自己的教材学习

- 先建立课程导览，再上传可提取文字的 PDF、DOCX、TXT 等课程资料。进入“教材与自测”选择教材，检查自动识别的目录，也可以粘贴并修改真实目录，然后保存教材选择。
- 系统区分“找到原文”“可能相关”“未找到”，并列出尚未对应导览的目录项。可逐项添加待补充章节，已有导览不会被自动覆盖。
- 在课程导览中生成或更新章节讲解时，会优先提供所选教材的相关片段，并保留原文来源。更换教材或修改目录后，已有讲解会提示需要复核，重新生成由你决定。
- 点击来源可查看原文片段；有原始附件时还能打开对应文件，PDF 带页码定位。扫描 PDF 可在资料页主动执行本机 OCR（最多前 20 页），提取失败的页及截断的内容仍需另行补充，不能把“未找到”理解为教材一定没有讲。
- 校准是目录与知识点的覆盖检查，不是事实正确性认证。AI 答案和题目也应结合原文检查；引用编号存在不等于引用支持整句话。
- 自己课程的“两题自测”使用已选择的教材和最多六个导览知识点出题。出题失败不保存伪造结果；答题后只反馈本次题目表现，不推断整门课掌握程度。

## 问答与 API 消耗

本机新版沿用本地服务配置。分享的 ZIP 只附空白 `.env.example`，接收者需要使用自己的密钥。复制为 `.env.local`，填写 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL` 后重启；密钥由服务端读取。支持现有 DeepSeek 配置和兼容的 Chat Completions 服务，模型名称及视觉能力以服务商实际支持为准。

- 浏览、手动笔记、知识图谱、教材覆盖检查、示例自测、复习安排预览和备份恢复不调用 AI。
- 主动生成章节、两道自测、复习草稿或发送问题会调用 AI；批量补全章节按每章分别调用。
- 学习对话逐段显示模型实际返回的回答，提供检索状态和“停止生成”。停止后保留已有文字并标注未完成；已经生成的部分仍可能计费。
- 默认检索使用本地 BM25 排序和有限课程词表。问答中的 **AI 语义改写** 默认关闭；开启会额外发起一次短请求，同问题有内存缓存，失败回退本地检索。它是“查询改写 + 关键词排序”，不是向量数据库或 embedding 模型。
- 图片提问继承原版能力，每条最多三张、每张不超过 5 MB；仅使用服务支持的视觉模型。扫描 PDF 可主动触发本机 OCR，每次最多前 20 页。

## 迁移与恢复

分享软件：把本 ZIP 发给对方，对方解压并启动即可体验示例课；**首次安装依赖需要网络和 Node.js，不是免安装离线 EXE**。

迁移自己的学习数据：

1. 在“设置与备份”点 **导出含附件迁移包**，得到一个 `.kb.json` 文件。
2. 在另一份增强版里点 **选择备份恢复**，查看课程、笔记、附件数量，再确认恢复。
3. 恢复会替换目标增强版当前工作区，建议先导出目标工作区留档。原版不会受影响。

迁移包包含课程、导览、讲解、笔记及草稿、对话、自测、题库和作答历史、复习计划、回收站内容、原始教材和对话图片，以及附件 SHA-256 校验。上限为 300 个附件、附件合计 50 MB、正文约 800 万字符；单次上传文件上限 20 MB。缺失或损坏的完整备份会拒绝恢复；并发修改时不会强行覆盖。

“正文 JSON 备份”是应急文字留档，不含附件。兼容导入原版 JSON，但其中的 PDF、图片不会凭标识自动恢复；界面会要求明确确认仅恢复文字，原附件需从原版另存后重新上传。完整迁移请使用新版含附件迁移包。

数据文件通常包含私人笔记与原文；软件 ZIP 与个人迁移包分开使用。运行目录里的 `.env.local` 不应发给别人。

## 验证与参考

- `npm test`：自动测试。
- `node tools/evaluate-retrieval.mjs`：免费检索评估。
- `node tools/evaluate-retrieval.mjs --live --base-url http://127.0.0.1:3002`：主动重跑四题真实问答对照，最多 8 次问答及 4 次短查询改写，会消耗 API；不修改学习数据。
- 改动和验证边界见 `docs/enhanced-version.md`；原始评估结果见 `docs/evaluation/`。
- 已有 ClassBuild、CourseForge 等参考和许可证保存在 `docs/course-guide-references.md`、`docs/design-references.md`。本次沿用其已有结构，没有引入整套外部平台或新增运行依赖。

运行故障时保留启动窗口中的错误信息，检查 Node.js 版本、联网情况和是否完整解压。不要把说明文字粘进网址，正确地址以启动窗口单独显示的 URL 为准。
