# 课伴 · 研学增强版 0.5

本版本提供教材阅读与问答、跨内容搜索、题库与复述练习、统一复习队列、引用核对、笔记历史和含附件备份。完整行为及限制见 [0.5 更新说明](docs/UPDATE-0.5.md)。

## 启动

1. 安装 Node.js 22.13 或以上版本。
2. 将 ZIP 完整解压到普通文件夹。
3. Windows 双击 `start.cmd`；macOS/Linux 执行 `sh start.sh`。首次需要联网安装锁定依赖。
4. 打开启动器显示的网址。默认从 `http://localhost:3002/` 开始查找空闲端口。
5. 保持启动窗口开启。数据在本目录 `.wrangler/`，不要删除它。

也可以执行 `npm ci` 后运行 `npm run start:local`。Windows 是本次实际验证的平台；macOS/Linux 启动脚本不代表已经完成实体系统测试。

## 不用 AI 也能体验

1. 进入原创示例课程，在“教材阅读”选择段落，试用“打开问答”和“专注阅读”。
2. 按 Ctrl+K 搜索“矩阵的秩”，把类型设为教材，直接打开对应段落。
3. 到“练习与错题 → 快速自测”体验原创示例题，核对后开始作答。
4. 在“复述练习”先用自己的话解释，再保存并对照原文，自行填写核对结论。
5. 在笔记中进入编辑、修改正文，使用“笔记历史”比较并恢复版本。
6. 查看复习计划中的“今日复习队列”，按可用时间复习到期笔记与题目。

## 连接 AI

打开“设置与备份 → 连接 AI”，填写服务地址、服务商实际支持的模型 ID 和自己的密钥；仅当模型确实支持图片时勾选图片输入。保存后点击“测试已保存的连接”。测试会向服务商发送一句连接问候，产生一次少量模型调用，不发送教材。

界面配置加密保存在本机数据库，学习迁移包不含密钥。启动器自动把解密所需的本机密钥保存在 `.env.local`，不要公开该文件。界面配置优先于原环境变量配置，清除界面配置后恢复使用环境文件。缺少或更换加密密钥后，可重新保存 AI 配置。

AI 问答、出题与复述核对会按用户操作发送对应资料与问题；模型结果仍需结合原文判断。源码包没有附带任何可用的付费 API 密钥。

## 数据与恢复

在设置中导出“含附件迁移包”，换电脑后选择备份并核对导入预览。笔记版本、复述、人工引用意见及复习记录均随学习数据迁移；AI 在新电脑单独配置。笔记最多保留最近 20 个编辑快照，每课程最多 200 次复述和 1000 条引用意见，工作区正文总量上限 8 MB。

回退前另存新版迁移包，再使用旧源码和更新前的旧数据备份。完整 Git 历史请使用 GitHub 克隆或 Git bundle，源码 ZIP 不含 Git 对象。团队信息仍待补充。演示视频独立准备，不包含在代码仓库中。
